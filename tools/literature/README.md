# 本机文献翻译试验服务

启动：`npm run literature:local`，保持进程运行后打开 http://127.0.0.1:7868/ 。网站开发版的文献板块提供同一入口；生产站没有此入口，也不包含该 Python 服务。

本机已有环境位于 node_modules/.qa/pdf2zh-venv。换电脑需 Python 3.13 创建相同位置的虚拟环境，再安装 `tools/literature/requirements-local.txt`。首次运行还需下载引擎字体和模型资源；没有实现一键安装。

流程：选择未加密文字型 PDF（20 MB / 100 页以内）→填写智谱 Key→全文翻译→中文/双语 PDF 与复核清单。模型固定 GLM-4-Flash，4条 PPV/SVV 术语见 glossary.csv；不读取网站设置中的 Key、模型或个人词库。服务商额度和价格以账号实际政策为准，不承诺永久免费的云端调用。

Key 通过本机请求和子进程标准输入传递，不进入命令参数、状态文件或浏览器存储。任务原文、OCR、结果保存在 Git 忽略的 node_modules/.qa/local-literature/jobs；不会自动清理。请自行妥善管理本机文献。服务仅监听127.0.0.1，检查Host和Origin，不支持公网部署。停服后重新启动不恢复页面当前任务，但文件仍在磁盘。

排版沿用最后一轮：参考文献整条保留原文；检测到的复杂统计图保留原图及中文图注。普通嵌入图片尝试OCR中文回填，空间不足/校验失败则保留原文并列入HTML复核表。识别器完全漏掉的内容仍可能没有逐项提示。医学用词、正文、数字与公式需人工校对，不支持扫描件的完整翻译。

验证：现有已知论文和两篇锁定论文的真实结果已保存于本机 .qa；最后一轮是复用真实译文的离线保护重排。新上传入口完成PDF限制/请求边界测试、网站回归、类型检查和构建；新上传入口已完成一次23页真实任务：总1286.3秒，引擎1173.7秒，中文与双语PDF各23页均可逐页渲染；这证明处理流程完成，不代表全文医学内容和排版已人工校对。

本机服务不经过Vercel函数；若要让所有网站用户直接使用，仍需确定长期运行的后台及算力成本，不能仅推送前端就获得该能力。
