# 纯浏览器文献翻译试验

## 方向与边界

文献入口使用 PDF.js 读取和渲染、Tesseract.js 在浏览器中识图、pdf-lib 在浏览器中生成图片式对照 PDF。默认智谱复用正式站已有的 `/api/glm/chat/completions`，用设置中的 Key 转发待译文字。其他模型和自定义地址由浏览器直接连接。无需部署文献处理服务或运行本机 Python 工具。

浏览器直连取决于服务商的跨域许可。可在网页点击「检查模型连接」发送短句测试。默认智谱的文献翻译直接从正文批次开始，避免额外消耗一次检查请求。OCR 首次需联网下载识别资源。模型额度和费用由用户账号决定。

## 使用

启动 `npm run dev`，打开文献翻译，选择PDF。可单独识别本页图片文字（无需Key），也可翻译当前页/全文，失败后继续已有任务。停止会阻止后续步骤，当前模型请求/OCR可能需要等待结束。文件和译文仅保留在页面内存，关闭模块或刷新后清除。

原图始终完整保留；右侧按编号显示原文与中文。纯数字和可识别的参考文献片段有意保留，数字/部分单位检查不通过则回退原文并提示。此规则不能保证识别全部参考文献、单位、公式或漏字。现阶段不是原位覆盖中文版，也不能声称达到BabelDOC效果。

导出PDF在浏览器完成：每个原文页与对照文字一起输出，超长对照自动续页。页面栅格化，中文不能作为可选中文字复制；文件页数可大于原论文。尚未识别或翻译的部分明确标注。大文件内存和速度仍需进一步测量。

## 实际验证（2026-11-12）

- 本机IAB真实上传已知3页PPV/SVV论文，页面读取/翻页成功。
- OCR初次整页默认模式混入刻度线且漏字；改为约3倍页面尺寸（上限1200万像素）和稀疏文字模式后，第2页新增19个区域，包含GREY ZONE、13、9、左右标签、日期。FLUID与RESPONDER仍分开识别，问号等完全漏识别项未逐项覆盖。
- 无真实模型Key参与的导出验证：浏览器下载9页、约4.2 MB PDF；打开并渲染首尾页成功，中文状态文字可读，原图保留，未译状态可见。不能将此文件当作实际中文翻译效果验收。
- 自动回归覆盖默认智谱复用网站接口、自定义智谱地址直连、数值/符号/部分单位变化拦截、OCR与原生文字重复过滤、参考文献片段保留。
- 实际模型翻译与全文耗时尚待在网站设置使用有效 Key 后验证。
