# 纯浏览器文献翻译试验

## 方向与边界

文献入口使用 PDF.js 读取和渲染、Tesseract.js 在浏览器中识图、pdf-lib 在浏览器中生成图片式对照 PDF。文献页单独配置智谱 Key，通过正式站已有的 `/api/glm/chat/completions` 转发待译文字，不再读取普通翻译的 Key。无需部署文献处理服务或运行本机 Python 工具。

配置时点击「保存并检查连接」发送短句测试，该检查也可能产生少量模型费用。验证通过后才保存文献配置并自动收起表单。正文翻译直接从批次开始，避免额外消耗一次检查请求。OCR 首次需联网下载识别资源。模型额度和费用由用户账号决定。

## 独立模型配置与计费（2026-11-19）

文献页使用 `glm-4-flashx-250414`。在[智谱标准 API Key 页面](https://bigmodel.cn/usercenter/proj-mgmt/apikeys)获取可调用该模型的 Key，或填写已有的适用标准 Key／历史兼容 Key；不要求所有旧 Key 重置。保存、替换和移除文献 Key 均不修改普通翻译的配置，没有文献配置时也不会借用普通翻译的 Key。

[官方价格](https://docs.bigmodel.cn/cn/guide/start/pricing)在 2026-11-19 为输入、输出各 0.10 元 / 百万 Token，实际费用以平台账单为准。费用提醒在填写 Key 前和发起连接检查前可见。页面不估算每篇论文的费用，也不承诺付费后一定不会限速或翻译一定准确。

文献 Key 默认只留在当前页面会话。用户主动勾选「在此浏览器记住文献 Key」后才写入本地浏览器存储，与普通翻译的记住 Key 设置独立。「保存并检查连接」会调用一次模型；失败保留表单和原配置，不把无效 Key 写入已保存配置。401 应核对 Key 和接口适用范围，不按欠费处理。

## 使用

启动 `npm run dev`，打开文献翻译，选择 PDF。文献 Key 未配置时自动展开表单；连接验证通过后点击「翻译整篇」，完成后点击「下载双语 PDF」。失败后主操作为「继续翻译整篇」，也可下载当前结果。「更多操作」提供翻译当前页、单独识图（无需 Key）、下载未翻译对照及识图开关。停止会阻止后续步骤，当前模型请求/OCR 可能需要等待结束。文件和译文仅保留在页面内存，关闭模块或刷新后清除。布局及交互说明见[文献页 UI](literature-ui.md)。

「页面对照」左侧显示原页，右侧按标题、左栏、右栏和图注重新换行。正文超出可用空间时，译页标「见续页」，后续正文按原顺序接着排。点击段落可查看英文和中文，并跳到对应续页；「段落对照」也提供文字版。出版标签、说明和「参考文献」标题翻译成中文，姓名、期刊标识、DOI、日期原值和可识别的编号参考文献条目保留。图片、较大的注释图标和找到的密集矢量图不覆盖，识别出的图片文字另列对照。复杂表格、独立公式和非常规分栏仍需人工查看。

导出 PDF 使用与网页相同的排版和续页。未译与未通过数字或单位检查的文字保留原文，在续页注明原因。PDF 是图片式对照，文字不能直接选择复制；可在网页的「段落对照」复制。文件页数可能大于原论文，大文件内存和速度仍需测量。

## 实际验证（2026-11-12）

- 本机IAB真实上传已知3页PPV/SVV论文，页面读取/翻页成功。
- OCR初次整页默认模式混入刻度线且漏字；改为约3倍页面尺寸（上限1200万像素）和稀疏文字模式后，第2页新增19个区域，包含GREY ZONE、13、9、左右标签、日期。FLUID与RESPONDER仍分开识别，问号等完全漏识别项未逐项覆盖。
- 无真实模型Key参与的导出验证：浏览器下载9页、约4.2 MB PDF；打开并渲染首尾页成功，中文状态文字可读，原图保留，未译状态可见。不能将此文件当作实际中文翻译效果验收。
- 自动回归覆盖默认智谱复用网站接口、自定义智谱地址直连、数值/符号/部分单位变化拦截、OCR与原生文字重复过滤、参考文献片段保留。
- 实际模型翻译与全文耗时尚待在网站设置使用有效 Key 后验证。

旧 Python 工具留在 tools/literature 作历史试验。
