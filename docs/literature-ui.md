# 文献页布局与交互

核心任务是选择英文论文，生成左右对照的中文译页并下载双语 PDF。

## 布局

从上到下为任务标题、选文件／已选文件、文献 Key 与计费状态、主操作、阅读工具和左右对照页。页尾保留离开页面前下载的提醒。医学内容及数字核对提示仍在阅读区可见。

| 页面状态 | 主操作 | 交互 |
| --- | --- | --- |
| 尚未选文件 | 选择 PDF | 文件要求直接位于选择区域。Key 配置与价格说明默认收起。 |
| 已选文件但未配置 Key | 保存并检查连接 | 自动展开 Key 表单并聚焦输入框。验证通过才保存、自动收起并聚焦翻译按钮；错误在输入框下显示，保留原配置。 |
| 已选文件且 Key 已配置 | 翻译整篇 | 一次处理全部页面。当前页翻译、单独识图和识图开关位于更多操作。 |
| 处理中途停止或失败 | 继续翻译整篇 | 保留已处理内容，只处理缺失内容；允许下载当前结果。 |
| 所有页面均有处理结果 | 下载双语 PDF | 主按钮自动切为下载。处理完成不表示所有译文已通过医学核对，待核对计数继续显示。 |

## 改动与认知成本

| 改动 | 降低的成本 |
| --- | --- |
| 选择 PDF 放在最前 | 首屏直接呈现任务入口，用户无需先阅读模型技术信息。 |
| Key 变为紧凑状态条 | 只在需要填写时展开；普通翻译与文献配置仍独立。模型全名、单价和数据处理说明按需展开。计费及费用承担方始终可见。 |
| 合并保存和检查连接 | 少一次单独检查的点击；检查失败不显示已保存，也不覆盖旧配置。 |
| 每阶段突出一个主操作 | 避免用户在当前页、全文、检查与下载之间比较。完成后直接引导下载。 |
| 将低频动作收进更多操作 | 默认工具栏仅保留主操作、阅读模式和翻页，降低视觉搜索量。 |
| 保留处理进度与核对状态 | 用户无需记忆哪些内容已完成；部分结果不冒充完整翻译或医学审核通过。 |

首次使用的常规路径从「保存 Key → 单独检查 → 选择 PDF → 翻译全文 → 下载」五次页面操作，改为「选择 PDF → 保存并检查 → 翻译整篇 → 下载」四次。已有配置时为选择、翻译、下载三次。此计数不含键盘输入、系统文件选择器、可选设置及获取 Key 的站外操作；没有据此声称实际耗时已降低某个百分比。

## 验证边界

自动检查覆盖既有文献处理与独立配置隔离。浏览器流程检查使用两页测试 PDF 和模拟模型回复，验证无效 Key 就地报错、验证后收起配置、整篇处理、主按钮切换与实际下载。模拟译文不作为医学翻译质量证据。真实论文的排版和导出逻辑没有改动；收费模型的实际质量与耗时仍需使用有效 Key 验收。
