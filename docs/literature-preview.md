# 文献翻译试验版

2026-11-04。本地技术验证，不是已发布功能，也不是 ima 接口集成。

## 使用

运行 `npm run dev`，进入「文献翻译 · 试验」。先在设置中配置自己的模型，再选择 PDF。点击「翻译当前页」才发送当前页文字和命中的术语表；PDF 文件在浏览器内解析，不上传完整文件。API 费用由所配置服务决定。

支持 20 MB / 100 页以内的英文文字型 PDF。原文页面与实验译文同页对照，点击区域查看完整文字；「段落对照」可查看不受版面尺寸限制的文本。可逐页翻译、缓存已完成页、下载当前页对照 TXT。缓存仅存在组件内存，切换模块或刷新会清除。

## 实现和局限

- PDF.js 在本地提取横排文字与坐标；按位置和字号推测段落。不具备语义版面识别，复杂多栏阅读顺序未保证。
- 原位置译文使用原页图片加白底译文覆盖层。不是重新生成 PDF，可能遮挡底纹、表格线，长译文可能缩小或截断；完整文字可在段落视图查看。
- 扫描页、图片中的字和旋转文字没有 OCR。公式、表格、图注识别不保证正确，不承诺整篇无遗漏。
- 复用现有模型设置，把命中术语作为提示传给模型；不保证模型必定遵守。优先用户词库，最多 80 项。
- 一次只翻译当前页，120 个块 / 18000 个原文字符以内；没有整篇批处理、保版式 PDF 导出或生产任务服务。
- 模型输出必须包含所有段落 ID；错误结果不会覆盖已有译文。沿用现有模型调用重试机制，尚无进行中的请求取消功能。

## 验证证据

- TypeScript 检查通过，Vitest 27 项测试通过（原有 21 项 + 新增 6 项），生产构建通过。
- 隔离 Chrome：合成三页双栏 PDF；上传不会触发翻译调用；未配置密钥禁用翻译；模拟模型结果按块覆盖；失败重试保留已有结果；翻页缓存；无文字页禁用翻译；TXT 下载；无效 PDF；390 px 手机布局无横向溢出。未出现页面 JavaScript 异常。
- 浏览器验证只用测试密钥与拦截的模拟响应，未发送真实文献到模型、未使用真实账户、未验证医学翻译质量。
- 本次没有用户原始 PDF（只有截图）。下一步必须用真实论文检查排版、术语、数字、单位、遗漏和耗时。
- 安装时在线依赖审计报告 10 项漏洞（4 moderate / 6 high），涉及现有依赖链（包括 Vite、Vitest、xlsx 等）；报告未列出新增 pdfjs-dist。没有自动升级无关依赖；本次不是安全审计或发布验收。
- 构建仍提示已有 `/index.css` 缺失和主包体积较大。PDF 阅读模块与 worker 单独加载。

## 继续投入的判断

先用 5–10 篇真实样本衡量：遗漏、双栏阅读顺序、术语一致性、数字单位、排版溢出、每页耗时和服务账单。若原位置覆盖无法达到阅读要求，应改用专门文档翻译/重排引擎；不把这个覆盖试验当作完整保版式方案。
